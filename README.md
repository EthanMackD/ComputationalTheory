# Computational Theory Module: SHA-256 in Python

This repository contains my work for the Computational Theory assessment. It implements the SHA-256 hash function from the Secure Hash Standard (NIST FIPS 180-4) in Python, step by step, in the Jupyter notebook `problems.ipynb`.

## Setup

1. Clone the repository: `git clone https://github.com/EthanMackD/ComputationalTheory.git`
2. Install the requirements: `pip install -r requirements.txt`
3. Open the notebook: `jupyter notebook problems.ipynb`

## Repository structure

- `problems.ipynb`: the notebook with my solutions to Problems 0 to 6.
- `requirements.txt`: the Python packages needed to run the notebook.
- `AGENTS.md`: the agents file supplied by the module.
